# Cuppa English ☕

Five minutes of English a day: British English practice for an Italian speaker living in the UK, at A2–B1 level.

Open `index.html` in a browser. There's no build step and no server code. Progress is saved in the browser (localStorage). You can move it to another device with the backup code in Settings.

## What's inside
- **Today**: a daily 5 or 10-minute session with flashcards (spaced repetition), grammar questions, one listening dictation, one speaking exercise and a "false friend".
- **Path**: 12 weeks from A2 to B1. Each week has five short days: Grammar, Words, Real life, Sounds & listening, and Review & write.
- **Real life**: 12 UK situations (GP, pharmacy, bank, phone calls, shops, café, neighbours, work, trains, landlord, invitations, 999). Each has key phrases, a conversation and a role-play.
- **Practice**: flashcards, speaking coach (speech recognition, or record-and-compare as a fallback), listening dictation, diary with automatic hints for common Italian-speaker mistakes, grammar quizzes, ear training, irregular verbs and false friends.
- **Quick check**: search in English or Italian across grammar rules, pronunciation, irregular verbs, false friends, confusing words, vocabulary and phrases. Any word can be heard aloud.

Audio uses the browser's built-in voices (en-GB preferred). The Italian help can be turned off with the 🇮🇹 button.
