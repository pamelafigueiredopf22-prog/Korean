# GCSE Mock Revision

Revision pack for **Chemistry Paper 2 (Foundation, AQA)** and **Maths Paper 1 (Higher, non-calculator)**.

| File | What it is | How to use it |
|---|---|---|
| `01-revision-guide.md` | Full revision guide in simple words, with worked examples. Maths topics start with "What you need first". | Read one section, then test yourself with the flashcards. |
| `02-flashcards.html` | 172 interactive flashcards. Tap to flip, mark "Got it" or "Need practice", then re-do the ones you missed. | Download it and open it in any web browser (works offline). Filter by subject or topic. |
| `02-flashcards.csv` | The same cards as a spreadsheet. | Import into Quizlet or Anki, or print. |
| `03-video-plan.md` | Plan for the video lessons, waiting for approval. | Read it and approve or suggest changes. |

**Suggested plan for tonight (about 3 hours):**
1. Chemistry guide, sections A1–A6 (60 min), then the Chemistry flashcards (20 min).
2. Break (10 min).
3. Maths guide: work through the examples with a pen and paper, without a calculator (75 min), then the Maths flashcards (20 min).
4. Quick look at the "Final checklist" at the end of the guide, then sleep.
