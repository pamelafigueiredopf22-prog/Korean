@scene MATHS | Number | Fractions: multiply and divide

@scene MATHS | Number | Negative and fractional powers

@scene MATHS | Number | Standard form

@scene MATHS | Number | Surds

@chapter 2. Algebra
@scene MATHS | Algebra | Expanding brackets
@need a letter stands for an unknown number
- 3(2x − 5) = **6x − 15** >> To expand a bracket, multiply everything inside by the term outside.
- (x + 3)(x − 5) >> For double brackets, multiply every term in the first by every term in the second.
- x² − 5x + 3x − 15 >> x times x is x squared. x times minus five is minus five x. Three times x is three x. Three times minus five is minus fifteen.
- = **x² − 2x − 15** >> Collect the x terms: x squared minus two x minus fifteen.
- (x + 4)² = (x + 4)(x + 4) = **x² + 8x + 16** >> Careful with squared brackets. Write it out twice. It is NOT x squared plus sixteen.

@scene MATHS | Algebra | Factorising
@need expanding brackets
@box Find two numbers | that MULTIPLY to c | and ADD to b
- 6x² + 9x = **3x(2x + 3)** >> Factorising is the opposite of expanding. First, take out common factors.
- x² + 7x + 12: multiply to 12, add to 7 >> For a quadratic, find two numbers that multiply to twelve and add to seven.
- 3 and 4 → **(x + 3)(x + 4)** >> Three and four. So it's x plus three, times x plus four.
- x² − 49 = **(x + 7)(x − 7)** >> The difference of two squares: x squared minus forty-nine is x plus seven, times x minus seven.
- 2x² + 7x + 3: a × c = 6 → 6 and 1 >> When there's a number in front of x squared, multiply a by c: six. Find two numbers that multiply to six and add to seven: six and one.
- 2x(x + 3) + 1(x + 3) = **(2x + 1)(x + 3)** >> Split the middle term and factorise in pairs. The answer is two x plus one, times x plus three.

@scene MATHS | Algebra | Solving equations
@need an equation is a balance
@box Balance | do the same | to BOTH sides
- 7x + 3 = 3x + 19 >> An equation is like a balance. Whatever you do to one side, do to the other.
- −3x: 4x + 3 = 19 >> Take three x from both sides: four x plus three equals nineteen.
- −3: 4x = 16 >> Take three from both sides: four x equals sixteen.
- ÷4: **x = 4** >> Divide by four: x equals four.
- 3(x − 2) = 2(x + 4) → 3x − 6 = 2x + 8 → **x = 14** >> With brackets, expand first. Then x minus six equals eight, so x equals fourteen.

@scene MATHS | Algebra | Rearranging formulae
@need solving equations
- Make x the subject: y = (3x − 2)/5 >> Rearranging works just like solving. Make x the subject of y equals three x minus two, all over five.
- × 5: 5y = 3x − 2 >> Multiply both sides by five.
- + 2: 5y + 2 = 3x >> Add two to both sides.
- ÷ 3: **x = (5y + 2)/3** >> Divide by three.
- Subject appears twice? Collect, then **factorise** >> If the letter appears twice, get both terms on one side, then factorise it out.

@scene MATHS | Algebra | Inequalities
@box Golden rule | × or ÷ by a negative | → FLIP the sign
- < less than · ≤ less than or equal to >> The open sign means less than. With a line underneath, it means less than or equal to.
- Number line: open circle for <, filled circle for ≤ >> On a number line, use an open circle for less than, and a filled circle for less than or equal to.
- 3x + 2 > 14 → 3x > 12 → **x > 4** >> Solve them like equations. Three x plus two is greater than fourteen, so x is greater than four.
- 5 − 2x ≤ 11 → −2x ≤ 6 >> Five minus two x is less than or equal to eleven. Take five: minus two x is less than or equal to six.
- ÷ −2 and FLIP: **x ≥ −3** >> Divide by minus two, and flip the sign, because we divided by a negative. x is greater than or equal to minus three.

@scene MATHS | Algebra | Sequences: the nth term
- 5, 8, 11, 14, … difference = +3 >> The gap between terms is plus three every time.
- So start with **3n**: 3, 6, 9, 12 >> So the rule starts with three n. That gives three, six, nine, twelve.
- Each term is 2 more → **3n + 2** >> Our sequence is two more each time. So the nth term is three n plus two.
- Check n = 1: 3 + 2 = 5 ✔ >> Check: when n is one, three plus two is five. Correct.
- Is 100 in it? 3n + 2 = 100 → n = 32.67 → **No** >> Is one hundred in the sequence? Solve three n plus two equals one hundred. n is not a whole number, so no.
- Quadratic sequence: halve the 2nd difference → an² >> For a quadratic sequence, the second differences are the same. Halve that number to get the n squared term, then find the linear part.

@scene MATHS | Algebra | Straight-line graphs
@need coordinates: along, then up
@diagram line_graph
- y = mx + c >> The equation of a straight line is y equals m x plus c.
- m = gradient (steepness) >> m is the gradient. It tells you how steep the line is.
- c = where it crosses the y-axis >> c is the y-intercept, where the line crosses the y-axis.
- Gradient = up ÷ across >> The gradient is the change in y divided by the change in x. Up, divided by across.
- (1, 5) and (3, 11): m = 6 ÷ 2 = 3 >> A line goes through one, five and three, eleven. Up six, across two, so the gradient is three.
- 5 = 3(1) + c → c = 2 → **y = 3x + 2** >> Put the point one, five into y equals three x plus c. Five equals three plus c, so c is two.

@scene MATHS | Algebra | Parallel and perpendicular lines
@box Perpendicular | flip it | change the sign | 2 → −1/2
- Parallel lines: **same gradient** >> Parallel lines have the same gradient.
- Perpendicular: gradients multiply to −1 >> Perpendicular lines meet at a right angle. Their gradients multiply to minus one.
- Gradient 2 → **−1/2** >> To find it, flip the gradient and change the sign. Two becomes minus a half.
- Gradient −3/4 → **4/3** >> Minus three quarters becomes four thirds.
- Rearrange first! 2y = 6x + 4 → y = 3x + 2 >> Always get y on its own first, so you can read the gradient.

@scene MATHS | Algebra | Solving quadratics
@need factorising
- x² + x − 12 = 0 >> To solve a quadratic, first make it equal zero.
- (x + 4)(x − 3) = 0 >> Factorise it: x plus four, times x minus three.
- **x = −4** or **x = 3** >> If two things multiply to zero, one of them must be zero. So x is minus four, or x is three.
- Formula: x = (−b ± √(b² − 4ac)) ÷ 2a >> If it won't factorise, use the quadratic formula. x equals minus b, plus or minus the square root of b squared minus four a c, all over two a.
- x² + 4x + 1 = 0 → (−4 ± √12) ÷ 2 >> For x squared plus four x plus one, that gives minus four, plus or minus root twelve, all over two.
- √12 = 2√3 → **x = −2 ± √3** >> Root twelve is two root three. Divide by two: minus two, plus or minus root three.

@scene MATHS | Algebra | Completing the square
@diagram parabola
- x² + 6x + 2 >> Completing the square. Take x squared plus six x plus two.
- Halve 6 → (x + 3)² >> Halve the six to get three. Write x plus three, squared.
- (x + 3)² − 9 + 2 >> But that bracket makes an extra nine, so subtract nine. Then add the two.
- = **(x + 3)² − 7** >> That gives x plus three, squared, minus seven.
- Turning point: **(−3, −7)** >> The turning point is minus three, minus seven. Change the sign inside the bracket, and keep the sign outside.
- Roots = where the graph crosses the x-axis >> On a graph, the roots, or solutions, are where the curve crosses the x-axis.

@scene MATHS | Algebra | Simultaneous equations
@box Elimination | same signs → subtract | different signs → add
- 3x + 2y = 16 and x + 2y = 8 >> Two equations, two unknowns. We want values that make both true.
- Same +2y → subtract: 2x = 8 >> Both have plus two y. Same signs, so subtract the equations. Two x equals eight.
- **x = 4** >> So x equals four.
- 4 + 2y = 8 → **y = 2** >> Put that back in: four plus two y equals eight, so y equals two.
- Check: 3(4) + 2(2) = 16 ✔ >> Always check in the other equation. Twelve plus four is sixteen. Correct.
- With a quadratic: **substitute** the linear one in >> If one equation is a quadratic, substitute the straight line equation into it, then solve the quadratic.

@scene MATHS | Algebra | Functions and proof
@box Proof facts | even: 2n | odd: 2n + 1 | consecutive: n, n + 1
- f(x) = 3x − 1 → f(4) = **11** >> A function is a rule. If f of x is three x minus one, then f of four is eleven.
- fg(x): do **g first**, then f >> For f g of x, do g first, then f. Work from the right.
- Inverse: y = 3x − 1 → x = (y + 1)/3 >> For the inverse, rearrange to make x the subject.
- f⁻¹(x) = (x + 1)/3 >> So f inverse of x is x plus one, all over three.
- n + (n + 1) + (n + 2) = 3n + 3 = **3(n + 1)** >> Proof: three consecutive numbers add to three n plus three, which is three times something. So it's always a multiple of three.

@chapter 5. Probability
@scene MATHS | Probability | Probability basics
@box Remember | P(not A) = 1 − P(A) | AND → multiply | OR → add
- 0 = impossible · 1 = certain >> Probability goes from zero, impossible, to one, certain.
- 3 red, 5 blue: P(red) = **3/8** >> A bag has three red and five blue balls. The probability of red is three out of eight.
- P(rain) = 0.3 → P(no rain) = **0.7** >> Probabilities add to one. If the chance of rain is zero point three, no rain is zero point seven.
- Expected: 3/8 × 40 = **15** >> If you pick forty times, you'd expect three eighths of forty: fifteen reds.
- P(heads AND six) = ½ × 1/6 = **1/12** >> For AND, multiply. For OR, add.
